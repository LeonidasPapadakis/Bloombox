Configuration

Adjust your greenhouse settings

⚠️

These are advanced settings. Changing these values affects how often the system checks its sensors and adjusts the greenhouse. All intervals are in milliseconds. If you are unsure, use the reset button below to restore safe defaults.

🕒 System Clock

By default your greenhouse syncs its clock from the internet. Switch to manual to set the time yourself — useful when the greenhouse is offline.

Manual time

Time of day to set the greenhouse's clock to.

📡 Sensor Reading Interval

How often temperature, humidity, and light sensors are read and logged.

seconds

🍃 Ventilation Check Interval

How often the system checks humidity and adjusts the vents. A shorter interval means faster response to changes.

milliseconds

💡 Lighting Check Interval

How often the system checks the light level and adjusts the LEDs. A shorter interval gives smoother dimming.

milliseconds

📶 Network

Connect your greenhouse to your home WiFi so it can reach the internet (for time sync, weather data, etc). If no WiFi is configured — or it can't connect — the greenhouse falls back to its own Bloombox hotspot so you can still reach this page.
